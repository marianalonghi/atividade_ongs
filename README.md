# Sistema de Apoio às ONGs e Protetores de Animais

Projeto desenvolvido em grupo na Residência Full Stack 5.0.

## Objetivo

Desenvolver uma aplicação web para auxiliar ONGs, abrigos e protetores independentes na gestão de animais, usuários, doações e voluntariado.

## Back-end

- Linguagem: Java
- Framework: Spring Boot
- API REST
